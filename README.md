# AI Website Copy Generator – Local Cafe/Restaurant Edition

## Project Overview
##Business Choosen-a cafe or restaurant 

This project demonstrates a structured prompt engineering system designed to generate high-converting website copy for local businesses.

For this task, I selected a real-world style business:

**Business Name:** Sasi Cafe  
**Location:** Duvvada, Vizag  
**Target Audience:** Students, working professionals, and families  
**Business Type:** Cozy, budget-friendly rooftop cafe  
**Primary Goal:** Increase walk-in customers  

This system generates complete, ready-to-publish website copy that local businesses can immediately use.

---

## Problem Statement

Many local cafes struggle with:

- Unclear messaging
- Weak value propositions
- Generic website content
- Poor call-to-action structure

Hiring professional copywriters can be expensive.  
This project solves that using structured prompt engineering and AI.

---

## Solution Approach

Instead of generating random AI content, I designed a **reusable master prompt framework** that:

- Collects structured business inputs
- Controls tone and positioning
- Generates benefit-focused website copy
- Produces strong walk-in focused CTAs
- Avoids generic AI language

The prompt ensures outputs feel:

- Location-specific
- Audience-targeted
- Conversion-driven
- Ready for real-world publishing

---

## Prompt Engineering Logic
prompt-logic 

The master prompt includes:

1. Business Details
   - Name
   - Location
   - Target audience
   - Unique positioning
   - Business goals

2. Structured Output Requests
   - Homepage copy
   - Services/Menu section
   - Multiple CTA variations

3. Tone Control
   - Warm
   - Friendly
   - Inviting
   - Non-robotic
   - Specific to Vizag

By structuring inputs clearly, the AI produces consistent, high-quality results for similar businesses.
